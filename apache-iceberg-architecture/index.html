Apache Iceberg Architecture

Inside the metadata tree: snapshots, manifests, and table state.

The Metadata Tree

Iceberg's power comes from its metadata tree architecture. Instead of tracking directories, Iceberg tracks individual files. The tree consists of:

  • Table Metadata File (JSON): The root of the table, tracking schema, partitioning, and the current snapshot.
  • Manifest List (Avro): A list of manifest files that make up a specific snapshot.
  • Manifest File (Avro): Tracks individual data files, including min/max statistics for pruning.
  • Data Files: The actual data, usually stored in Parquet or ORC format.
