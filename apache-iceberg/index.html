Apache Iceberg Explained

The standard open table format powering the modern data lakehouse.

What is Apache Iceberg?

Apache Iceberg is a high-performance format for huge analytic tables. Iceberg brings the reliability and simplicity of SQL tables to big data, while making it possible for engines like Spark, Trino, Flink, and Dremio to safely work with the same tables, at the same time.

Key Capabilities

  • Schema Evolution: Add, drop, update, or rename, and reorder columns without side-effects.
  • Hidden Partitioning: Iceberg handles the tedious and error-prone task of producing partition values for rows.
  • Time Travel & Rollback: Reproducible queries using exact table snapshots, or easily roll back to earlier versions.
