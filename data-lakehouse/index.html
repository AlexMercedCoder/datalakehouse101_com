What Is a Data Lakehouse?

The definitive guide to understanding modern data lakehouse architecture.

Introduction

The data lakehouse is an open architecture that combines the flexibility and scale of data lakes with the performance, reliability, and governance of data warehouses. This paradigm shift relies on open table formats like Apache Iceberg to provide ACID transactions directly on cloud object storage.

Why the Data Lakehouse Emerged

Historically, organizations had to maintain two separate systems: data lakes for unstructured data and machine learning, and data warehouses for business intelligence. This led to data silos, expensive ETL pipelines, and stale data. The data lakehouse eliminates this divide.

The Layered Architecture

  • Storage Layer: Cloud object storage (S3, ADLS, GCS).
  • Metadata & Table Format Layer: Open formats (Iceberg, Delta Lake, Hudi) providing structure.
  • Compute & Semantic Layer: Engines like Dremio, Spark, or Trino processing the data.
